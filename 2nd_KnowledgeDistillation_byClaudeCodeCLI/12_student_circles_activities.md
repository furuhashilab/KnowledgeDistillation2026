# 学生サークル・活動内容詳細

## サークル構成と役割

古橋研究室の学生は以下の5つのユニットに所属して活動する。

```
古橋研究室
├── YouthMappers AGU部（ユースマッパーズ）
├── V&F（Video & Film）部
├── Design部
├── Drone部
├── YOKOZE部（よこぜぶ）
└── ヤマッ部（やまっぶ）
```

---

## YouthMappers AGU部

### 概要
- **国際所属**: YouthMappers国際ネットワーク（世界30校以上）の日本拠点
- **活動**: OpenStreetMapを通じた社会貢献マッピング
- **レベル**: 初心者〜経験者まで幅広く受け入れ

### 主要活動内容
1. **マパソン（マッピングマラソン）**: 集団でのHOT Tasking Manager作業
2. **HOT Tasking Manager 活用**: 人道支援マッピング
3. **バリデーション**: 他マッパーの作業品質確認
4. **国際連携**: SotM等での発表・交流
5. **チュートリアル制作**: 入門動画・記事の作成

### 主要プロジェクト実績
| 年度 | プロジェクト | 成果 |
|---|---|---|
| 2022 | ウクライナ難民支援マッピング | 建物・農地・道路マッピング |
| 2024 | タイ南部洪水バリデーション | 336名参加、6日で50%完了 |
| 2025 | セブ島地震バリデーション | HOT TM #32511 |
| 2025 | ヨロン島マパソン | 農地マッピング、1月22日 |
| 2025 | SotMマニラ発表 | バングラデシュマッピング報告 |

### 役割分担パターン
```
初心者: マッピング作業（タスク選択→建物トレース→アップロード）
中級者: バリデーション作業（品質確認・修正）
上級者: プロジェクト管理・チュートリアル制作・国際発表
```

## V&F（Video & Film）部

### 概要
- **役割**: 研究室の映像制作とSNS発信を担当
- **成果物**: プロモーション動画、活動記録、チュートリアル動画
- **ライセンス**: CC BY 4.0 での公開

### 主要メンバー事例（2024年度）
- **高井**（Takai）: V&F + Design 掛け持ち、プロモーション動画制作
- **古内**（Furuuchi）: 災害アーカイブ制作（Re:Earth活用）

### 制作ワークフロー
```
企画 → 絵コンテ（ストーリーボード）
→ 撮影（インタビュー、ドローン映像、スクリーン録画）
→ 素材共有（Google Drive）
→ 編集（DaVinci Resolve / CapCut）
→ 品質チェック（音量、字幕、尺、ライセンス）
→ YouTube 公開（CC BY 4.0）
→ Medium でブログ記事連携
```

### 技術スキルセット
- DaVinci Resolve（カット編集、カラーグレーディング）
- Adobe After Effects（モーショングラフィックス）/ CapCut（モバイル編集・ショート動画）
- Google Earth Studio → FFmpeg → MP4変換
- OBS（ライブ配信・画面録画）
- 360°カメラ（Insta360、Ricoh Theta）

## Design部

### 概要
- **役割**: 3Dモデリング、グラフィックレコーディング（グラレコ）、ブランドデザイン
- **ツール**: Blender、3Dプリンター、Adobe Illustrator、Figma

### グラフィックレコーディング（グラレコ）
- イベント・講義をリアルタイムで手描きイラスト+文字で記録
- 研究室の全ハッカソン・イベントで実施
- 教育コンテンツとして後から参照可能

### 3Dモデリング・ガチャ制作
```
テーマ決定（毎年4月頃のジオ展に向けて）
→ Blenderモデリング（1〜2週間）
→ STLエクスポート
→ 3Dプリント出力
→ 後処理・塗装
→ ジオ展でガチャ販売（50〜100円/個）
```

### 主要制作物
- **ドローンシリーズ**: DJI、Skydio、Sensefly等、多数
- **武甲山（横瀬町）**: 2026年ハッカソン成果
- **カメラシリーズ**: GoPro、OSMO等
- **ロゴ・ブランドデザイン**: logos4gsc2024（GSC学部用）

## Drone部

### 概要
- **役割**: 災害研究、ドローン国家資格取得、空撮測量
- **資格**: 2022年制度化のドローン国家資格（1種・2種）取得推進

### スキルレベル別活動
```
入門: トイドローン（Tello等）でホバリング練習
初級: 屋外でDJI機体を使った基本飛行
中級: 法規制確認・申請→撮影→ODMで処理
上級: 点群・SfM解析→地図データ化→社会実装
```

### 代表的フィールド活動
| 活動 | 場所 | 目的 |
|---|---|---|
| 伊豆大島廃林調査 | 伊豆大島 | 植生変化モニタリング |
| 横瀬川河川調査 | 埼玉県横瀬町 | 河川地形3Dデータ化 |
| 草津市空撮 | 滋賀県草津市 | OAMへの投稿 |
| 横瀬町ドローン体験 | 埼玉県横瀬町 | 地域イベント向けデモ |

### 安全・法規則
- DID（人口集中地区）での飛行: 国土交通省許可申請が必要
- 高度150m以上: 許可申請が必要
- 飛行前チェック: 天候（Windy）、バッテリー、規制エリア確認

## 研究室の学習文化

### 「連れ回される」文化
> 研究室の特徴として「連れ回される」（主体的に動かされる）文化がある。
> 外部のイベント・フィールドワークに積極的に参加し、実践から学ぶ。

### AI活用と倫理
- ChatGPT/Gemini/NotebookLMを学習支援ツールとして活用
- **ハルシネーション対策ルール**: AI出力に事実誤認が3件以上あれば発表やり直し
- GitHub公開方針: AIに生成させたコードも含めてGitHubで透明性確保

### 発表・プレゼンのガイドライン
- ビジュアルの明確さ > データの精密さ
- 手法の透明性（再現可能性）を重視
- 比較可視化テクニックの活用
- 「なぜ」を「何を」より優先した説明
