## V&F（Video & Film）部の活動

### 映像制作プロセス
```
企画・絵コンテ作成
→ ロケ（空撮・インタビュー・演出）
→ 編集（Adobe Premiere Pro / After Effects）
→ BGM選定（ライセンス確認必須）
→ テロップ・字幕追加
→ Media Encoder でエンコード
→ YouTube/Medium 公開
→ CC BY 4.0 ライセンス付与
```

### 主要制作ツール
| ツール | 用途 |
|---|---|
| Adobe Premiere Pro | 映像編集主力ツール |
| Adobe After Effects | モーショングラフィックス |
| Adobe Media Encoder | 最終エンコード |
| Google Earth Studio | 地球ズームイン・地理アニメーション |
| FFmpeg | コマンドライン変換（GEStudio→MP4等）|
| OBS | スクリーン録画・ライブ配信 |
| DaVinci Resolve | カラーグレーディング（一部）|
| Insta360 / Ricoh Theta | 360°カメラ撮影 |

### 主要成果物
- **研究室プロモーション動画（2024年）**: 3〜5分、CC BY 4.0、V&F部員（高井・古内）制作
- **研究室プロモーション動画（2025年）**: 2〜3分、ハッカソン形式で制作、全ユニット紹介
- **TEDx AGU 2020 バーチャルイベント**: クロマキー合成 + YouTube/Zoom配信

## グラフィックレコーディング（グラレコ）

### グラフィックレコーディングとは
講義・会議・イベントの内容をリアルタイムで手描きのイラストと文字で記録する手法。

### 研究室でのグラレコ活用
- 全ハッカソン・イベントでの記録
- Mediumブログ記事のビジュアル補完
- 学習内容の視覚化・理解促進

### グラレコ教育の系譜
```
野村（研究室グラレコ先駆者）
→ 堀
→ 安田
→ 高井（2024〜2025年、Minecraft防災にも応用）
```

### グラレコ研修

  - セッション1〜4（35秒〜9:22）

## 映像コンテンツの品質基準

### 公開前チェックリスト（V&F部門）
- [ ] BGMのボリュームと著作権ライセンス確認
- [ ] 字幕（テロップ）の有無と正確さ
- [ ] 解像度（最低1080p推奨）
- [ ] 動画尺（テンポ・不要部分カット）
- [ ] 各ユニット（Youth、Drone、Design、V&F）の紹介バランス
- [ ] URL・リンクの正確さ
- [ ] クレジット表記

### ライセンス方針
- 研究室公開動画: **CC BY 4.0**（氏名表示4.0国際）
- OSMデータを含む場合: **ODbL**表記追加
- BGM: Creative Commons または有料購入ライセンス

## 技術的メモ（映像制作）

### Google Earth Studio 使用メモ
- 出力: JPEGシーケンス
- FFmpegでMP4変換:
```bash
# パターンマッチングオプション指定が必要
ffmpeg -pattern_type none -r 30 -i frame_%04d.jpg -r 60 output.mp4
```

### 360°カメラのGPS付与
```
問題: Insta360/Ricoh Theta は内蔵GPSがない場合がある
解決: Stravaで同時にGPX記録 → Mapillary UploaderでGPXを読み込み
注意: 自動アップロードはOFF推奨（品質管理のため手動チェック）
```
